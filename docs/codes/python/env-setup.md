# Python environment setup

One project, three toolchains — pick whichever the repo already uses.

## venv

Standard-library virtual environments: creating one, activating it, and
freezing/restoring the dependency set.

## conda

Environment creation with a pinned Python version, and how the environment
carries outside the project directory.

## poetry

Project-local dependency management, where the environment lives inside the
project and is never activated by hand.
